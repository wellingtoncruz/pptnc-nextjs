Story 9.4: API e Tela de Listagem de Usuários

Status: review

Story

As a administrador do podcast, I want ver uma lista de todos os usuários autorizados, so that eu possa visualizar quem tem acesso ao sistema e suas informações.

Acceptance Criteria

AC1: API GET /api/users

DADO um usuário autenticado como admin
QUANDO eu chamar GET /api/users
ENTÃO deve retornar lista de usuários com:
  - id, email, name, picture, role, lastAccessAt, createdAt
E deve estar ordenada por lastAccessAt DESC (mais recente primeiro)
E deve excluir usuários soft-deleted

DADO um usuário autenticado como 'user' (não admin)
QUANDO eu chamar GET /api/users
ENTÃO deve retornar 403 Forbidden

AC2: Proteção da rota /videos?view=users

DADO um usuário não-admin
QUANDO ele acessar /videos?view=users diretamente
ENTÃO deve ser redirecionado para /videos
E não deve ver conteúdo de usuários

AC3: Componente UserListPanel

DADO a tela de usuários carregada
QUANDO os dados forem buscados com sucesso
ENTÃO deve exibir uma lista/tabela com:
  - Avatar do usuário (imagem ou iniciais)
  - Nome completo
  - Email
  - Badge de Role (Admin/Usuário)
  - Último acesso (formato relativo: "há 2 horas")
E deve ter estado de loading enquanto busca
E deve ter estado de erro com botão retry

AC4: Indicador de usuário atual

DADO a lista de usuários
QUANDO eu visualizar meu próprio usuário
ENTÃO deve haver um indicador "(você)" ou similar
E não deve ser possível ações sobre si mesmo

AC5: Estado vazio

DADO que não há outros usuários além do atual
QUANDO a lista carregar
ENTÃO deve mostrar mensagem informativa
E explicar que novos usuários aparecem após primeiro login

Formatação de data relativa:

// Se date-fns não estiver instalado, usar:
const formatRelativeTime = (date: Date): string => {
  const now = new Date()
  const diff = now.getTime() - date.getTime()
  const minutes = Math.floor(diff / 60000)
  const hours = Math.floor(diff / 3600000)
  const days = Math.floor(diff / 86400000)

  if (minutes < 1) return 'agora'
  if (minutes < 60) return `há ${minutes} min`
  if (hours < 24) return `há ${hours}h`
  return `há ${days}d`
}
