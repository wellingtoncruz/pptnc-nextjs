Apêndice — Troubleshooting

401 Unauthorized durante AC2:

  • API key inválida ou revogada. Verificar em https://console.anthropic.com → API keys.
  • Key começa com sk-ant-api03- — confirma o formato.

429 Rate limit durante stress (AC5):

  • Tier 1 tem cap baixo (50 RPM, 30K ITPM Sonnet). Esperar 1min e retry.
  • Pra produção, depositar mais e subir tier ($40 → Tier 2; $200 → Tier 3; $400 → Tier 4).

404 model not found:

  • Confirmar claude-sonnet-4-6 é o ID correto (ou tentar claude-sonnet-4-5).
  • Algumas keys têm acesso limitado a model families — checar permissions no console.
