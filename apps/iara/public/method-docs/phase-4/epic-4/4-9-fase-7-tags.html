Story 4.9: Fase 7 - Tags (Tipo 1)

Status: done

Story

As a produtor, I want tags otimizadas para SEO geradas pela IA, so that o video seja encontrado mais facilmente no YouTube.

Acceptance Criteria

  1. AC1: Processamento Automatico ao Entrar na Fase

    • Given o Wizard na Fase 7
    • When a fase inicia
    • Then processamento LLM e iniciado automaticamente
    • And Area de Interatividade mostra loading state

  2. AC2: Exibicao de Tags Geradas

    • Given tags geradas pelo LLM
    • When renderizadas na Area de Interatividade
    • Then mostra lista de tags como chips/badges
    • And cada tag pode ser removida individualmente
    • And produtor pode adicionar novas tags manualmente
    • And limite de 500 caracteres total (limite YouTube)

  3. AC3: Input de Complemento de Prompt

    • Given a fase renderizada
    • When o produtor visualiza
    • Then ve input de texto para {additionalContext}
    • And input tem placeholder com dica de uso
    • And input tem maximo de 200 caracteres

  4. AC4: Botao Revalidar

    • Given o botao "Revalidar" clicado
    • When com complemento de prompt preenchido
    • Then nova chamada LLM com {additionalContext} no prompt
    • And tags anteriores sao substituidas pelas novas
    • And NAO marca nenhuma fase posterior (fase 7 e a ultima com LLM)

  5. AC5: Console Area com Feedback

    • Given o processamento LLM em andamento
    • When a fase esta processando
    • Then Console Area mostra:
      • Spinner: "Pensando nas melhores tags para o video..."
    • And apos retorno mostra Alert:
      • Titulo: "Tags"
      • Texto: "Adicione e remova tags conforme necessario."

  6. AC6: Persistencia no Firestore

    • Given tags editadas pelo produtor
    • When salvas
    • Then campo tags e persistido na raiz do objeto video
    • And estrutura: Array<string>

  7. AC7: Criterios de Avanco

    • Given os criterios de avanco da Fase 7
    • When o botao "Avancar" e clicado
    • Then valida:
      • Retorno do LLM com sucesso
      • Campo tags persistido (pelo menos 1 tag)
    • And se todos atendidos, avanca para Fase 8
    • And se algum faltar, botao permanece desabilitado

  8. AC8: Comportamento Fase Tipo 1 (Reprocessavel)

    • Given esta e uma fase Tipo 1 (Reprocessavel)
    • When renderizada
    • Then mostra input de additionalContext
    • And mostra botao "Revalidar"
    • And permite reprocessamento multiplo
    • And permite edicao livre das tags

  9. AC9: Tratamento de Erros

    • Given a chamada LLM falha
    • When erro e recebido
    • Then Console Area mostra Alert de erro com mensagem amigavel
    • And permite tentar novamente (botao retry habilitado)

  10. AC10: Exibicao com Dados Persistidos

    • Given tags ja existentes (video.tags existe)
    • When a fase e aberta
    • Then exibe as tags existentes como chips
    • And permite edicao e revalidacao

Dev Notes

Architecture Patterns

  • Fase Tipo 1 (Reprocessavel): Pode ser reprocessada com additionalContext. O componente permite reprocessar e editar livremente.
  • Processamento Automatico: Igual as Fases anteriores, inicia processamento automaticamente ao entrar.
  • Console Pattern: Usar wizard.addSpinner() ao iniciar, wizard.removeSpinner() ao finalizar, wizard.addAlert() para resultado.
  • Ultima Fase LLM: Fase 7 e a ultima que usa LLM. Fase 8 e apenas envio para YouTube.

Response Schema (Phase7Response)

interface Phase7Response {
  tags: string[]  // Array of 10-20 tags
}

Already defined in src/lib/llm/types.ts.

YouTube Tag Limits

  • Maximum 500 characters total for all tags combined
  • Each tag should be relevant to the video content
  • Mix of specific and general tags

Console Messages Pattern

// Inicio do processamento
const spinnerId = wizard.addSpinner(7, 'Pensando nas melhores tags para o video...')

// Apos sucesso
wizard.removeSpinner(spinnerId)
wizard.addAlert(7, 'Tags', 'Adicione e remova tags conforme necessario.', 'success')

// Apos erro
wizard.removeSpinner(spinnerId)
wizard.addAlert(7, 'Erro', errorMessage, 'error')

Difference from Phase 6

  • Uses chips/badges instead of textarea
  • Users can add/remove individual tags
  • Character limit is 500 (YouTube limit) instead of 5000
  • No needsRevalidation for subsequent phases (this is the last LLM phase)
  • Revalidation doesn't need confirmation dialog
