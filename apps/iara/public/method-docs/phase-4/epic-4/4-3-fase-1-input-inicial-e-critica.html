Story 4.3: Fase 1 - Input Inicial e Crítica (Tipo 2)

Status: done

Story

As a produtor, I want informar contexto e receber uma crítica sincera do episódio, so that tenho feedback especializado sobre o conteúdo antes de continuar o processamento.

Acceptance Criteria

  1. AC1: Área de Interatividade na Fase 1

    • Given o Wizard aberto na Fase 1
    • When a fase é renderizada
    • Then Área de Interatividade mostra:
      • Campos de contexto já preenchidos (via Story 4.0b)
      • Botão "Processar Crítica" para iniciar LLM

  2. AC2: Processamento LLM com Console Feedback

    • Given o botão "Processar Crítica" clicado
    • When a chamada LLM inicia
    • Then Console Area mostra:
      • Spinner: "Estou assistindo o episódio para te dar uma opinião sincera..."
      • Após retorno: Alert com título "Crítica do Especialista" e texto formatado

  3. AC3: Persistência da Crítica

    • Given a crítica retornada do LLM
    • When salva no Firestore
    • Then campo phases.1.data contém a estrutura Phase1Response
    • And fase muda para status completed
    • And próxima fase (2) é desbloqueada

  4. AC4: Comportamento Fase Tipo 2 (Imutável)

    • Given esta é uma fase Tipo 2 (Imutável)
    • When renderizada após completada
    • Then NÃO mostra input de override nem botão de reprocessar
    • And crítica é gerada uma única vez
    • And exibe apenas o resultado em modo read-only

  5. AC5: Exibição da Crítica

    • Given a crítica foi processada
    • When exibida na Área de Interatividade
    • Then mostra:
      • Crítica geral em formato de texto
      • Lista de Highlights (pontos fortes)
      • Lista de Sugestões (melhorias)

  6. AC6: Tratamento de Erros

    • Given a chamada LLM falha
    • When erro é recebido
    • Then Console Area mostra Alert de erro com mensagem amigável
    • And permite tentar novamente (botão fica habilitado)

Dev Notes

Architecture Patterns

  • Fase Tipo 2 (Imutável): Uma vez processada, não pode ser reprocessada. O componente deve detectar phases[1].status === 'completed' e renderizar em modo read-only.
  • Chamada LLM Síncrona: Usa callLLM de @/lib/llm com timeout de 60s (PHASE_TIMEOUTS[1]).
  • Console Pattern: Usar wizard.addSpinner() ao iniciar, wizard.removeSpinner() ao finalizar, wizard.addAlert() para resultado.
