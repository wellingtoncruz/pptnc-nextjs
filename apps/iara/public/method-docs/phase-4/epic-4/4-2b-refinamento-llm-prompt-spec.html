Story 4.2b: Refinamento LLM - Prompt Spec (llm.md)

Status: done

Story

As a sistema, I want que as chamadas LLM sigam a especificação definida em llm.md, so that os prompts sejam montados dinamicamente usando personas e prompts configurados no podcast.

Acceptance Criteria

AC1: Template de Prompt conforme llm.md

  1. Given uma chamada LLM para qualquer fase When o prompt é construído Then segue o template definido em llm.md:
    Seu papel: {persona.role}
Seu objetivo: {persona.objective}
Seu contexto: {persona.resume}
Sua tarefa: {prompts.{videoType}.{phase}.description}
Seu retorno deve ser estritamente: {prompts.{videoType}.{phase}.expectedOutput}

AC2: Configuração da Fase 1 (Crítica)

  1. Given a Fase 1 (Crítica) When a chamada LLM é feita Then usa persona podcast.personas.critic And usa prompts de podcast.prompts.{videoType}.critique And o anexo é transcriptionTXT (não SRT)

AC3: Transcrição como Anexo de Arquivo

  1. Given a transcrição do vídeo When enviada para a API Gemini Then é salva em arquivo temporário And passada como ANEXO (file attachment) na requisição And NÃO é enviada inline no prompt

AC4: Interpolação de Placeholders

  1. Given os placeholders no template When o prompt é interpolado Then {persona.role} → podcast.personas.{personaName}.role And {persona.objective} → podcast.personas.{personaName}.objective And {persona.resume} → podcast.personas.{personaName}.resume And {prompts.{videoType}.{phase}.description} → podcast.prompts.{videoType}.{phase}.description And {prompts.{videoType}.{phase}.expectedOutput} → podcast.prompts.{videoType}.{phase}.expectedOutput

AC5: Fallback para Prompts Base

  1. Given podcast sem personas/prompts configurados When a chamada LLM é feita Then usa os prompts padrão de BASE_SYSTEM_PROMPTS como fallback And log indica que usou fallback

// ADICIONAR - função para construir prompt conforme llm.md
export function buildPhasePrompt(
  phase: WizardPhase,
  persona: Persona | undefined,
  prompts: Prompts | undefined,
  videoType: VideoType
): string {
  // Se não tem persona ou prompts configurados, usar fallback
  if (!persona || !prompts) {
    return getSystemPrompt(phase) // fallback existente
  }

  const config = PHASE_CONFIG[phase]
  const phasePrompts = prompts[videoType]?.[config.promptKey]

  if (!phasePrompts?.description || !phasePrompts?.expectedOutput) {
    return getSystemPrompt(phase) // fallback
  }

  // Template conforme llm.md
  return `Seu papel: ${persona.role}
Seu objetivo: ${persona.objective}
Seu contexto: ${persona.resume}
Sua tarefa: ${phasePrompts.description}
Seu retorno deve ser estritamente: ${phasePrompts.expectedOutput}`
}

client.ts:

// MODIFICAR - callLLM para aceitar podcast
export async function callLLM<P extends Exclude<WizardPhase, 8>>(
  phase: P,
  video: Video,
  podcast?: Podcast, // NOVO parâmetro
  options?: LLMCallOptions
): Promise<LLMResult<PhaseResponseMap[P]>> {
  // ... validação existente ...

  // Extrair persona e prompts do podcast
  const config = PHASE_CONFIG[phase]
  const persona = podcast?.personas?.[config.personaName]
  const prompts = podcast?.prompts

  // Construir prompt
  const systemPrompt = options?.promptOverride
    ? options.promptOverride
    : buildPhasePrompt(phase, persona, prompts, video.videoType)

  // Log modo usado
  if (persona && prompts) {
    log('INFO', 'Using configured prompts', { phase, personaName: config.personaName })
  } else {
    log('INFO', 'Using fallback prompts', { phase })
  }

  // Determinar qual transcrição usar
  const transcription = config.attachmentType === 'TXT'
    ? video.transcriptionTXT
    : video.transcriptionSRT

  // Criar arquivo temporário e passar como attachment
  const fileUri = await createTranscriptionFile(transcription)

  try {
    const { data, usage } = await callVertexAIWithAttachment<PhaseResponseMap[P]>(
      systemPrompt,
      userPrompt,
      fileUri,
      timeout
    )
    return { success: true, data, usage }
  } finally {
    await cleanupTempFile(fileUri) // Limpar arquivo temporário
  }
}
