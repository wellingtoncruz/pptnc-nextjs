Story 4.8: Fase 6 - Descricao (Tipo 1)

Status: done

Story

As a produtor, I want uma descricao otimizada para SEO gerada pela IA, so that o video seja encontrado mais facilmente no YouTube.

Acceptance Criteria

  1. AC1: Processamento Automatico ao Entrar na Fase

    • Given o Wizard na Fase 6
    • When a fase inicia
    • Then processamento LLM e iniciado automaticamente
    • And Area de Interatividade mostra loading state

  2. AC2: Exibicao de Descricao Gerada

    • Given descricao gerada pelo LLM
    • When renderizada na Area de Interatividade
    • Then mostra textarea com descricao gerada (editavel)
    • And textarea permite edicao livre
    • And alteracoes sao salvas com auto-save
    • And contador de caracteres (max 5000)

  3. AC3: Input de Complemento de Prompt

    • Given a fase renderizada
    • When o produtor visualiza
    • Then ve input de texto para {additionalContext}
    • And input tem placeholder com dica de uso
    • And input tem maximo de 200 caracteres

  4. AC4: Botao Revalidar com Confirmacao

    • Given o botao "Revalidar" clicado
    • When com complemento de prompt preenchido
    • Then Alert Dialog solicita confirmacao
    • And mensagem informa que fase 7 sera marcada para revalidacao
    • And se confirmado: nova chamada LLM com {additionalContext} no prompt
    • And fase 7 e marcada com needsRevalidation: true (dados preservados)

  5. AC5: Console Area com Feedback

    • Given o processamento LLM em andamento
    • When a fase esta processando
    • Then Console Area mostra:
      • Spinner: "Calculando uma descricao otimizada para voce..."
    • And apos retorno mostra Alert:
      • Titulo: "Descricao"
      • Texto: "Confira a descricao e faca os ajustes se necessario:"

  6. AC6: Persistencia no Firestore

    • Given descricao editada pelo produtor
    • When salva
    • Then campo description e persistido na raiz do objeto video
    • And capitulos sao incluidos automaticamente no formato YouTube

  7. AC7: Criterios de Avanco

    • Given os criterios de avanco da Fase 6
    • When o botao "Avancar" e clicado
    • Then valida:
      • Retorno do LLM com sucesso
      • Campo description persistido
    • And se todos atendidos, avanca para Fase 7
    • And se algum faltar, botao permanece desabilitado

  8. AC8: Comportamento Fase Tipo 1 (Reprocessavel)

    • Given esta e uma fase Tipo 1 (Reprocessavel)
    • When renderizada
    • Then mostra input de additionalContext
    • And mostra botao "Revalidar"
    • And permite reprocessamento multiplo
    • And permite edicao livre do texto

  9. AC9: Tratamento de Erros

    • Given a chamada LLM falha
    • When erro e recebido
    • Then Console Area mostra Alert de erro com mensagem amigavel
    • And permite tentar novamente (botao retry habilitado)

  10. AC10: Exibicao com Dados Persistidos

    • Given descricao ja existente (video.description existe)
    • When a fase e aberta
    • Then exibe a descricao existente no textarea
    • And permite edicao e revalidacao

Dev Notes

Architecture Patterns

  • Fase Tipo 1 (Reprocessavel): Pode ser reprocessada com additionalContext. O componente permite reprocessar e editar livremente.
  • Processamento Automatico: Igual as Fases 2-5, inicia processamento automaticamente ao entrar, sem botao manual.
  • Console Pattern: Usar wizard.addSpinner() ao iniciar, wizard.removeSpinner() ao finalizar, wizard.addAlert() para resultado.
  • SEO Chain: A descricao usa o titulo selecionado na Fase 5 e sera usada pela Fase 7 (Tags).
  • Auto-save com Debounce: Salvar alteracoes com debounce de 1.5s para evitar muitas chamadas.

Similarity with Phase 5

Phase 6 follows similar pattern as Phase 5:

  • Type 1: Reprocessable with additionalContext
  • Auto-processing on phase entry
  • Console messages pattern
  • Revalidation marks subsequent phase(s)

Differences from Phase 5:

  • Textarea instead of radio buttons (editable text vs selection)
  • Auto-save with debounce instead of selection-based save
  • Only marks phase 7 (not 6 and 7 like phase 5)
  • Character counter for description (max 5000)
