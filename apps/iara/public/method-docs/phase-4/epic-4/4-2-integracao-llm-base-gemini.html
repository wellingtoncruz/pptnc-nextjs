Story 4.2: Integração LLM Base (Gemini API)

Status: done

Story

As a sistema, I want um cliente configurado para a API do Gemini com chamadas síncronas, so that eu possa gerar metadados de vídeos em cada fase do Wizard.

Acceptance Criteria

AC1: Cliente Gemini

  1. Given a necessidade de chamar o Gemini When eu uso callLLM(phase, video, promptOverride?) Then a requisição é enviada para a API do Gemini And aguarda resposta completa (sem streaming) And timeout de 30-60s por chamada And retorna JSON parseado ou erro

AC2: Prompts por Fase

  1. Given os prompts por fase When eu chamo getPromptForPhase(phase, video, config) Then retorna o prompt interpolado com variáveis:
    • {title}: título original do vídeo
    • {transcript}: transcrição do vídeo (SRT)
    • {duration}: duração formatada
    • {theme}: tema do episódio
    • {guests}: dados dos convidados formatados
    • {previousPhaseData}: dados das fases anteriores (para SEO chain) And para cut/reel, busca contexto do parentEpisodeId

AC3: Error Handling

  1. Given erro de LLM (rate limit, timeout, invalid response) When a chamada falha Then retorna erro estruturado { code: string, message: string } And a aplicação NÃO muda de fase And mostra mensagem amigável ao usuário
