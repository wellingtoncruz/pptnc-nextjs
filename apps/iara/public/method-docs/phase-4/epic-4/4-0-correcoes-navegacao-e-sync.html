Story 4.0: Correções de Navegação e Sincronização

Status: done

Story

As a produtor de conteúdo, I want que a sincronização de vídeos respeite as regras de visibilidade do YouTube e que vídeos já enviados fiquem inacessíveis para edição, so that eu trabalhe apenas em vídeos que ainda precisam de processamento e não edite acidentalmente vídeos já publicados.

Acceptance Criteria

AC1: Botão "Verificar Novos" com Loading State

  1. Given o usuário na tela de vídeos When ele clica no botão "Verificar Novos" Then o layout é travado com overlay semi-transparente And um spinner é exibido centralizado And o botão fica desabilitado durante a operação And nenhuma interação é permitida até o sync completar

  2. Given a sincronização em andamento When ela completa com sucesso Then o overlay e spinner são removidos And a lista de vídeos é atualizada And toast mostra resumo: "X novos vídeos encontrados" ou "Nenhum vídeo novo"

  3. Given a sincronização em andamento When ocorre um erro Then o overlay e spinner são removidos And toast de erro é exibido com mensagem descritiva And o usuário pode tentar novamente

AC2: Vídeos sent Ofuscados e Sem Interação

  1. Given a lista de vídeos renderizada When um vídeo tem status sent Then o item é exibido com opacidade reduzida (opacity-50) And o cursor muda para not-allowed And o clique não seleciona o vídeo And não atualiza a URL com ?selected=

  2. Given um vídeo com status sent na lista When o usuário passa o mouse sobre ele (hover) Then aparece tooltip com texto: "Para trabalhar nesse video, torne ele Privado ou Não Listado" And o tooltip usa posicionamento adequado (não corta na borda)

  3. Given navegação por teclado (↑/↓) When o próximo vídeo na sequência tem status sent Then a seleção pula para o próximo vídeo não-sent And se todos abaixo/acima são sent, a seleção não move

AC3: Regras de Visibilidade para Novos Vídeos

  1. Given a sincronização busca vídeos do YouTube When um vídeo novo tem visibilidade "Rascunho" (Draft) Then é criado no Firestore com status new

  2. Given a sincronização busca vídeos do YouTube When um vídeo novo tem visibilidade "Não Listado" (Unlisted) Then é criado no Firestore com status new

  3. Given a sincronização busca vídeos do YouTube When um vídeo novo tem visibilidade "Privado" (Private) Then é criado no Firestore com status new

  4. Given a sincronização busca vídeos do YouTube When um vídeo novo tem visibilidade "Público" (Public) Then é criado no Firestore com status sent And aparece na lista já ofuscado

AC4: Reavaliação de Vídeos sent

  1. Given a sincronização é executada When existem vídeos com status sent no Firestore Then a visibilidade atual de cada um é verificada no YouTube

  2. Given um vídeo com status sent When sua visibilidade no YouTube mudou para "Não Listado" Then seu status muda para draft And ele volta a ser clicável na lista And toast informa: "X vídeos voltaram para edição"

  3. Given um vídeo com status sent When sua visibilidade no YouTube mudou para "Privado" Then seu status muda para draft And comportamento igual ao AC12

  4. Given um vídeo com status sent When sua visibilidade no YouTube continua "Público" Then seu status permanece sent And nenhuma alteração é feita

AC5: Persistência do Campo de Visibilidade

  1. Given qualquer operação de sync When dados do vídeo são salvos/atualizados no Firestore Then o campo visibility é persistido com valor: 'public' | 'unlisted' | 'private' | 'draft' And o campo visibilityUpdatedAt registra o timestamp da última verificação

AC6: Modal de Feedback Após Sync

  1. Given a sincronização completa com sucesso When foram encontrados novos vídeos ou vídeos reabraram para edição Then um modal é exibido com o resumo:

    • "Encontrados X novos vídeos"
    • "Y vídeos voltaram para edição" (se houver) And o modal tem botão "Entendi" para fechar

  2. Given a sincronização completa com sucesso When nenhum novo vídeo foi encontrado Then o modal mostra: "Nenhum vídeo novo encontrado"

  3. Given a sincronização falha When ocorre erro de quota da API YouTube Then o modal mostra mensagem amigável: "Limite de requisições excedido. Tente novamente em alguns minutos."

AC7: Verificação e Download de Transcrição

  1. Given um vídeo novo com status new When a sincronização processa o vídeo Then o sistema verifica se transcriptionSRT e transcriptionTXT estão preenchidos And se ambos estiverem vazios, busca legendas PT_BR auto-geradas no YouTube

  2. Given um vídeo sent que mudou para draft (via reopen) When a reavaliação é processada Then o sistema também verifica a transcrição (mesma lógica do AC19)

  3. Given existem legendas PT_BR auto-geradas no YouTube When o sistema busca as legendas Then faz download do arquivo SRT And converte para texto puro (TXT) removendo timestamps And persiste ambos: transcriptionSRT e transcriptionTXT

  4. Given NÃO existem legendas PT_BR no YouTube When o sistema verifica as legendas Then os campos transcriptionSRT e transcriptionTXT permanecem vazios And o vídeo fica marcado como "pendente de transcrição"

AC8: Bloqueio de Vídeos Pendentes de Transcrição

  1. Given um vídeo com status new ou draft When os campos transcriptionSRT e transcriptionTXT estão vazios Then o item é exibido com opacidade reduzida (opacity-50) And o cursor muda para not-allowed And o clique não seleciona o vídeo

  2. Given um vídeo pendente de transcrição na lista When o usuário passa o mouse sobre ele Then aparece tooltip: "Transcrição ainda em processamento, aguarde."

  3. Given navegação por teclado When o próximo vídeo está pendente de transcrição Then a seleção pula para o próximo vídeo disponível

Dev Notes

YouTube API - Privacy Status

A YouTube Data API retorna o campo status.privacyStatus com valores:

  • public - Vídeo público
  • unlisted - Não listado
  • private - Privado

Para vídeos em "Rascunho" no YouTube Studio, o valor é private com um campo adicional. Verificar se há distinção ou tratar ambos como editáveis.

// Exemplo de response do YouTube API
{
  "id": "abc123",
  "status": {
    "privacyStatus": "unlisted",
    "uploadStatus": "processed"
  }
}

Mapeamento de Visibilidade → Status Inicial

function getInitialStatus(privacyStatus: string): VideoStatus {
  if (privacyStatus === 'public') {
    return 'sent'
  }
  return 'new'
}

Transição de sent → draft

A state machine atual não tem transição sent → draft. Será necessário:

Opção A: Adicionar nova action reopen que permite sent → draft Opção B: Bypass da state machine para esta operação específica (não recomendado)

Recomendação: Opção A - Adicionar transição na state machine:

// Em transitions.ts
sent: { reopen: 'draft' }  // Nova transição

YouTube Captions API

A YouTube Data API fornece endpoints para listar e baixar legendas:

// 1. Listar legendas de um vídeo
// GET https://www.googleapis.com/youtube/v3/captions?part=snippet&videoId={videoId}
{
  "items": [
    {
      "id": "caption-id-1",
      "snippet": {
        "videoId": "abc123",
        "language": "pt-BR",
        "trackKind": "ASR",  // ASR = auto-generated
        "name": ""
      }
    }
  ]
}

// 2. Baixar legenda em formato SRT
// GET https://www.googleapis.com/youtube/v3/captions/{captionId}?tfmt=srt

Filtro de legendas:

  • trackKind === 'ASR' = legendas auto-geradas
  • language deve ser 'pt' ou 'pt-BR'
  • Priorizar pt-BR sobre pt se ambas existirem

Parser SRT → TXT

Formato SRT:

1
00:00:00,000 --> 00:00:02,500
Primeira linha de texto

2
00:00:02,500 --> 00:00:05,000
Segunda linha de texto
com continuação

Conversão para TXT:

Primeira linha de texto

Segunda linha de texto com continuação

Regras do parser:

  • Remover número de sequência (linha 1, 2, 3...)
  • Remover linha de timestamp (00:00:00,000 --> 00:00:00,000)
  • Juntar linhas de texto do mesmo bloco com espaço
  • Separar blocos com dupla quebra de linha

Verificação de Transcrição Pendente

function isPendingTranscription(video: Video): boolean {
  // Apenas vídeos new ou draft podem estar pendentes
  if (video.status !== 'new' && video.status !== 'draft') {
    return false
  }
  // Pendente se ambos campos estão vazios
  return !video.transcriptionSRT && !video.transcriptionTXT
}
