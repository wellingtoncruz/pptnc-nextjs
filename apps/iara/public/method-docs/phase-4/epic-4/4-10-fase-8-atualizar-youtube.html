Story 4.10: Fase 8 - Atualizar YouTube

Status: done

Story

As a produtor, I want enviar os metadados finalizados para o YouTube, so that as alteracoes sejam publicadas no meu canal.

Acceptance Criteria

  1. AC1: Exibicao do Resumo de Metadados

    • Given o Wizard na Fase 8
    • When a fase e renderizada
    • Then Area de Interatividade mostra:
      • Titulo final (video.title)
      • Preview da descricao (primeiros 200 caracteres de video.description)
      • Contagem de tags (video.tags.length)
      • Contagem de capitulos (video.chapters.length)
    • And botao "Enviar para o YouTube"

  2. AC2: Inicio do Envio

    • Given o botao "Enviar para o YouTube" clicado
    • When a requisicao inicia
    • Then botao mostra loading state (disabled + spinner)
    • And Console Area mostra spinner: "Enviando metadados para o YouTube..."
    • And status do video muda para sending (via video state machine)

  3. AC3: Envio Bem-Sucedido

    • Given envio bem-sucedido
    • When YouTube retorna 200
    • Then status muda para sent (via video state machine)
    • And Console Area mostra Alert de sucesso:
      • Titulo: "Publicado!"
      • Texto: "Os metadados foram atualizados no YouTube com sucesso."
    • And botao muda para "Concluido" (disabled, estado final)

  4. AC4: Erro no Envio

    • Given erro no envio
    • When YouTube retorna erro
    • Then status permanece ready (nao muda para sending)
    • And Console Area mostra Alert de erro com mensagem amigavel
    • And botao volta ao estado normal para retry
    • And permite tentar novamente

  5. AC5: Sem Processamento LLM

    • Given esta fase
    • When renderizada
    • Then NAO possui processamento LLM
    • And NAO possui input de additionalContext
    • And NAO possui botao Revalidar
    • And NAO processa automaticamente ao entrar

  6. AC6: Validacao Pre-Envio

    • Given o botao "Enviar para o YouTube" clicado
    • When validacao pre-envio e executada
    • Then valida que todos os campos obrigatorios existem:
      • video.title nao vazio
      • video.description nao vazio
      • video.tags com pelo menos 1 tag
    • And se algum faltar, mostra erro e nao envia

  7. AC7: Formatacao de Chapters na Descricao

    • Given chapters existem no video
    • When descricao e enviada ao YouTube
    • Then chapters sao formatados no inicio da descricao
    • And formato: 00:00 Titulo do Capitulo\n
    • And descricao original segue apos os chapters

Dev Notes

Architecture Patterns

  • Fase Final (Sem LLM): Nao possui processamento LLM, apenas chamada a YouTube API.
  • Console Pattern: Usar wizard.addSpinner() ao iniciar envio, wizard.removeSpinner() ao finalizar, wizard.addAlert() para resultado.
  • Video State Machine: Usar transition(status, action) para gerenciar mudancas de status:
    • ready -> send -> sending
    • sending -> success -> sent
    • sending -> error -> ready

Chapters Formatting

// Formato YouTube para chapters:
// 00:00 Introducao
// 05:30 Topico 1
// 15:45 Topico 2

function formatChaptersForYouTube(chapters: Chapter[]): string {
  return chapters
    .map(c => `${c.timestamp} ${c.title}`)
    .join('\n')
}

// Descricao final:
const finalDescription = chapters.length > 0
  ? `${formatChaptersForYouTube(chapters)}\n\n${description}`
  : description
