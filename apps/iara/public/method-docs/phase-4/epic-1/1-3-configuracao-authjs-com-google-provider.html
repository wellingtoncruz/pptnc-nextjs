Story 1.3: Configuracao Auth.js com Google Provider

Status: done

Story

Como um usuario, Eu quero fazer login usando minha conta Google, Para que eu possa acessar o sistema de forma segura.

Acceptance Criteria

AC1: Botao de login visivel

Given um usuario nao autenticado When ele acessa a pagina de login Then ve um botao "Entrar com Google"

AC2: Fluxo de autenticacao Google

Given um usuario clica em "Entrar com Google" When ele autoriza o acesso no popup do Google Then e redirecionado para a pagina principal autenticado And sua sessao e criada com dados do perfil (nome, email, avatar)

AC3: Fluxo de logout

Given um usuario autenticado When ele clica em "Sair" Then sua sessao e encerrada And e redirecionado para a pagina de login

AC4: Configuracao Auth.js v5

Given o projeto configurado When eu verifico a configuracao de auth Then Auth.js v5 esta configurado em src/lib/auth.ts And existe um arquivo src/app/api/auth/[...nextauth]/route.ts

AC5: SessionProvider wrapper

Given a necessidade de acessar sessao no client When eu verifico os providers Then existe um SessionProvider wrapper em src/components/providers/session-provider.tsx And o layout root usa este provider

AC6: getServerSession disponivel

Given a necessidade de acessar sessao no server When eu verifico as funcoes exportadas Then a funcao auth() esta disponivel para Route Handlers e Server Components

AC7: Variaveis de ambiente configuradas

Given o projeto configurado When eu verifico as variaveis de ambiente Then existem: AUTH_GOOGLE_ID, AUTH_GOOGLE_SECRET, AUTH_SECRET And existe arquivo .env.example documentando as variaveis

AC8: Pagina de login implementada

Given um usuario nao autenticado When ele acessa /login Then ve a pagina de login com branding do IAra And botao "Entrar com Google" centralizado And dark mode aplicado

AC9: Redirect apos login

Given um usuario completa o login When a autenticacao e bem sucedida Then e redirecionado para /videos And se havia uma URL de origem, volta para ela

AC10: Testes de autenticacao

Given o modulo de auth When eu executo os testes Then testes verificam:

  • Configuracao do Google Provider
  • Callbacks de sessao
  • Funcao auth() retorna sessao valida

Dev Notes

Auth.js v5 (NextAuth v5)

Auth.js v5 e a versao mais recente, com mudancas significativas da v4:

Instalacao:

pnpm add next-auth@beta

Configuracao base (src/lib/auth.ts):

import NextAuth from 'next-auth'
import Google from 'next-auth/providers/google'

export const { handlers, signIn, signOut, auth } = NextAuth({
  providers: [
    Google({
      clientId: process.env.AUTH_GOOGLE_ID!,
      clientSecret: process.env.AUTH_GOOGLE_SECRET!,
    }),
  ],
  pages: {
    signIn: '/login',
  },
  callbacks: {
    async jwt({ token, account }) {
      if (account) {
        token.accessToken = account.access_token
      }
      return token
    },
    async session({ session, token }) {
      // Adicionar dados extras a sessao se necessario
      return session
    },
  },
})

Route handler (src/app/api/auth/[...nextauth]/route.ts):

import { handlers } from '@/lib/auth'

export const { GET, POST } = handlers
export const runtime = 'nodejs'

SessionProvider (src/components/providers/session-provider.tsx):

'use client'

import { SessionProvider as NextAuthSessionProvider } from 'next-auth/react'

export function SessionProvider({ children }: { children: React.ReactNode }) {
  return <NextAuthSessionProvider>{children}</NextAuthSessionProvider>
}

GCP Console Setup

  1. Acessar Google Cloud Console
  2. Criar ou selecionar projeto
  3. APIs & Services > Credentials
  4. Create Credentials > OAuth 2.0 Client ID
  5. Application type: Web application
  6. Authorized redirect URIs:
    • http://localhost:3000/api/auth/callback/google (dev)
    • https://your-domain.com/api/auth/callback/google (prod)

Verificar Sessao em Server Components

import { auth } from '@/lib/auth'

export default async function ProtectedPage() {
  const session = await auth()

  if (!session) {
    redirect('/login')
  }

  return <div>Ola, {session.user?.name}</div>
}

Verificar Sessao em Route Handlers

import { auth } from '@/lib/auth'
import { NextResponse } from 'next/server'

export async function GET() {
  const session = await auth()

  if (!session) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
  }

  return NextResponse.json({ user: session.user })
}

Enforcement Rules Aplicaveis

  1. Route Handler Runtime (Rule #3): Incluir export const runtime = 'nodejs'
  2. Structured Logging (Rule #9): Usar log() para erros de auth
  3. Error Response Format (Rule #5): { error: { code, message } }
