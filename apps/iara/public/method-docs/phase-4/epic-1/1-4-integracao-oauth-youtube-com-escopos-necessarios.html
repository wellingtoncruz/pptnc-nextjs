Story 1.4: Integração OAuth YouTube com Escopos Necessários

Status: done

Story

Como um usuário, Eu quero autorizar o acesso à API do YouTube durante o login, Para que o sistema possa ler meus vídeos e atualizar metadados.

Acceptance Criteria

AC1: Consent screen com permissões YouTube

Given um usuário fazendo login pela primeira vez When ele autoriza no Google Then a consent screen solicita permissões do YouTube:

  • youtube.readonly (ler vídeos do canal)
  • youtube.force-ssl (atualizar metadados - equivale ao antigo youtube.upload) And o usuário pode ver quais permissões está concedendo

AC2: Login subsequente sem re-autorização

Given um usuário que já autorizou anteriormente When ele faz login novamente Then não precisa re-autorizar (refresh_token é usado)

AC3: Tratamento de negação de permissões

Given um usuário nega as permissões do YouTube When o fluxo de OAuth retorna Then o usuário vê uma mensagem explicando que as permissões são necessárias And pode tentar novamente

AC4: Escopos configurados no Auth.js

Given a configuração do Auth.js When eu verifico os escopos Then os escopos OAuth estão configurados no Google provider:

  • openid
  • email
  • profile
  • https://www.googleapis.com/auth/youtube.readonly
  • https://www.googleapis.com/auth/youtube.force-ssl

AC5: Access token disponível server-side

Given um usuário autenticado When eu verifico a sessão no server Then o access_token do YouTube está disponível And pode ser recuperado via callbacks do Auth.js

AC6: Refresh token preservado

Given um usuário autoriza pela primeira vez When o callback OAuth é processado Then o refresh_token é capturado e preservado And na próxima autorização, o refresh_token NÃO é sobrescrito

AC7: Prompt de consent para novos escopos

Given um usuário com sessão existente When novos escopos são adicionados à configuração Then o prompt do Google solicita autorização para os novos escopos And preserva o refresh_token existente

Dev Notes

Escopos YouTube Necessários

Escopos corretos para Auth.js v5:

authorization: {
  params: {
    scope: 'openid email profile https://www.googleapis.com/auth/youtube.readonly https://www.googleapis.com/auth/youtube.force-ssl',
    access_type: 'offline',
    prompt: 'consent',
  },
},

Detalhes dos escopos:

  • youtube.readonly: Leitura de vídeos, playlists, canal do usuário
  • youtube.force-ssl: Gerenciamento de vídeos incluindo update de metadados (título, descrição, tags)

IMPORTANTE: O escopo youtube.upload mencionado no PRD/Architecture não existe. O escopo correto para atualizar metadados é youtube.force-ssl.

Configuração Completa do Google Provider

// src/lib/auth.ts
import NextAuth from 'next-auth'
import Google from 'next-auth/providers/google'

export const { handlers, signIn, signOut, auth } = NextAuth({
  providers: [
    Google({
      clientId: process.env.AUTH_GOOGLE_ID!,
      clientSecret: process.env.AUTH_GOOGLE_SECRET!,
      authorization: {
        params: {
          scope: 'openid email profile https://www.googleapis.com/auth/youtube.readonly https://www.googleapis.com/auth/youtube.force-ssl',
          access_type: 'offline',
          prompt: 'consent',
        },
      },
    }),
  ],
  pages: {
    signIn: '/login',
    error: '/auth/error',
  },
  callbacks: {
    async jwt({ token, account }) {
      // Primeira autenticação - capturar todos os tokens
      if (account) {
        token.accessToken = account.access_token
        token.expiresAt = account.expires_at
        // CRÍTICO: Só salvar refresh_token se vier (primeira autorização)
        if (account.refresh_token) {
          token.refreshToken = account.refresh_token
        }
      }
      return token
    },
    async session({ session, token }) {
      if (token.sub) {
        session.user.id = token.sub
      }
      return session
    },
  },
})

Página de Erro de Autorização

// src/app/auth/error/page.tsx
import Link from 'next/link'
import { Button } from '@/components/ui/button'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

interface AuthErrorPageProps {
  searchParams: Promise<{ error?: string }>
}

export default async function AuthErrorPage({ searchParams }: AuthErrorPageProps) {
  const { error } = await searchParams

  const errorMessages: Record<string, { title: string; message: string }> = {
    access_denied: {
      title: 'Permissões Necessárias',
      message: 'O IAra precisa de acesso ao seu canal do YouTube para funcionar. Por favor, autorize as permissões solicitadas.',
    },
    default: {
      title: 'Erro de Autenticação',
      message: 'Ocorreu um erro durante a autenticação. Tente novamente.',
    },
  }

  const errorInfo = errorMessages[error || 'default'] || errorMessages.default

  return (
    <div className="flex min-h-screen items-center justify-center bg-background p-4">
      <Card className="w-full max-w-md">
        <CardHeader>
          <CardTitle className="text-destructive">{errorInfo.title}</CardTitle>
        </CardHeader>
        <CardContent className="space-y-4">
          <p className="text-muted-foreground">{errorInfo.message}</p>
          <div className="flex gap-2">
            <Button asChild>
              <Link href="/login">Tentar Novamente</Link>
            </Button>
          </div>
        </CardContent>
      </Card>
    </div>
  )
}
