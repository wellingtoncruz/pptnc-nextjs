Status: done

Story

Como um desenvolvedor, Eu quero ter o projeto Next.js 15+ configurado com shadcn/ui e estrutura de pastas padrão, Para que eu possa começar a implementar funcionalidades seguindo a arquitetura definida.

Acceptance Criteria

AC1: Projeto Next.js 15+ criado

Given um ambiente de desenvolvimento limpo When eu executo os comandos de setup do projeto Then o projeto Next.js 15+ é criado com App Router habilitado

AC2: TypeScript strict mode

Given o projeto criado When eu verifico tsconfig.json Then TypeScript 5.x está configurado em modo strict

AC3: Tailwind CSS v4 configurado

Given o projeto criado When eu verifico a configuração do Tailwind Then Tailwind CSS v4 está configurado com OKLCH colors e @theme inline

AC4: shadcn/ui inicializado

Given o projeto criado When eu verifico os componentes Then shadcn/ui está inicializado com tema dark-only

AC5: Estrutura de pastas

Given o projeto criado When eu verifico a estrutura de diretórios Then a estrutura de pastas segue o padrão da architecture:

  • src/app/ para rotas
  • src/components/ para componentes
  • src/lib/ para utilitários
  • src/types/ para tipos TypeScript

AC6: Vitest configurado

Given o projeto criado When eu verifico a configuração de testes Then Vitest está configurado para testes unitários

AC7: Structured logging

Given o projeto criado When eu verifico a lib de logging Then o arquivo lib/logger.ts existe com função log() para structured logging

AC8: Linting configurado

Given o projeto criado When eu verifico as ferramentas de lint Then ESLint e Prettier estão configurados

AC9: Build funciona

Given o projeto configurado When eu executo pnpm build Then o projeto compila sem erros

lib/logger.ts Template

type LogLevel = 'INFO' | 'WARN' | 'ERROR'

interface LogPayload {
  [key: string]: unknown
}

export function log(level: LogLevel, message: string, payload?: LogPayload): void {
  const entry = {
    severity: level,
    message,
    timestamp: new Date().toISOString(),
    ...payload,
  }

  if (level === 'ERROR') {
    console.error(JSON.stringify(entry))
  } else {
    console.log(JSON.stringify(entry))
  }
}

test-utils.tsx Template

import { render, RenderOptions } from '@testing-library/react'
import { ReactElement } from 'react'

function AllTheProviders({ children }: { children: React.ReactNode }) {
  return <div id="portal-root">{children}</div>
}

function customRender(ui: ReactElement, options?: Omit<RenderOptions, 'wrapper'>) {
  return render(ui, { wrapper: AllTheProviders, ...options })
}

export * from '@testing-library/react'
export { customRender as render }
