Story 1.7: Token Refresh e Gestão de Sessão Expirada

Status: done

Story

Como um usuário, Eu quero que minha sessão seja mantida automaticamente, Para que eu não precise fazer login frequentemente.

Acceptance Criteria

AC1: Refresh automático de access_token

Given um access_token próximo da expiração (< 5 min) When uma requisição autenticada é feita Then o token é automaticamente renovado usando o refresh_token And o novo access_token é persistido no Firestore And a requisição original é completada com sucesso

AC2: Tratamento de refresh_token inválido

Given um refresh_token inválido ou revogado When uma tentativa de refresh é feita Then o usuário é deslogado And é redirecionado para /login And vê mensagem "Sessão expirada, faça login novamente"

AC3: Resposta 401 padronizada para API

Given uma requisição API com sessão expirada When o servidor processa a requisição Then retorna status 401 And body contém { error: { code: 'AUTH_EXPIRED', message: 'Sessão expirada' } }

AC4: Detecção de 401 no frontend

Given o frontend recebe resposta 401 When a resposta é processada Then o usuário é redirecionado para /login And a URL original é preservada como callbackUrl

AC5: Lógica de refresh no jwt callback

Given o callback jwt do Auth.js When um token está próximo de expirar Then o refresh é executado automaticamente And structured logging registra a operação

AC6: Testes unitários

Given testes para token refresh When eu executo pnpm test Then testes cobrem cenários de token expirado And testes cobrem refresh bem-sucedido And testes cobrem refresh_token inválido

Google OAuth Token Refresh

Para renovar o access_token usando refresh_token:

// POST https://oauth2.googleapis.com/token
const response = await fetch('https://oauth2.googleapis.com/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({
    client_id: process.env.AUTH_GOOGLE_ID!,
    client_secret: process.env.AUTH_GOOGLE_SECRET!,
    grant_type: 'refresh_token',
    refresh_token: storedRefreshToken,
  }),
})

// Response
{
  access_token: "new-access-token",
  expires_in: 3600,
  scope: "...",
  token_type: "Bearer"
}
// NOTE: refresh_token NÃO é retornado no refresh (apenas na primeira auth)

Auth.js jwt Callback com Refresh

callbacks: {
  async jwt({ token, account }) {
    // Initial sign in
    if (account) {
      return {
        ...token,
        accessToken: account.access_token,
        refreshToken: account.refresh_token,
        expiresAt: account.expires_at,
      }
    }

    // Return existing token if not expired
    if (Date.now() < (token.expiresAt as number) * 1000 - 5 * 60 * 1000) {
      return token
    }

    // Token expired or expiring soon - refresh
    try {
      const refreshed = await refreshAccessToken(token.refreshToken as string)

      // Persist to Firestore
      await saveUserTokens(token.sub!, {
        accessToken: refreshed.accessToken,
        expiresAt: refreshed.expiresAt,
      })

      return {
        ...token,
        accessToken: refreshed.accessToken,
        expiresAt: refreshed.expiresAt,
      }
    } catch (error) {
      log('ERROR', 'Token refresh failed', { userId: token.sub, error })
      return { ...token, error: 'RefreshAccessTokenError' }
    }
  },
}

Frontend - Detecção de 401

// src/lib/api/fetch-with-auth.ts
export async function fetchWithAuth(url: string, options?: RequestInit) {
  const response = await fetch(url, options)

  if (response.status === 401) {
    const currentPath = window.location.pathname + window.location.search
    window.location.href = `/login?callbackUrl=${encodeURIComponent(currentPath)}&expired=true`
    throw new SessionExpiredError()
  }

  return response
}
