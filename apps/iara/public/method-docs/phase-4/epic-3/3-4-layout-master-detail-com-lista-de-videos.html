Story 3.4: Layout Master-Detail com Lista de Vídeos

Status: done

Story

As a usuário, I want um layout com lista de vídeos à esquerda e detalhes à direita, so that eu possa navegar e visualizar vídeos eficientemente.

Acceptance Criteria

  1. Given um usuário acessa /videos When a página carrega Then vê layout Master-Detail com:

    • Sidebar fixa à esquerda (w-48, colapsável)
    • Painel de lista de vídeos (largura ajustável)
    • Painel de detalhes à direita

  2. Given o layout carregado When o usuário arrasta o divisor entre painéis Then os painéis são redimensionados And a preferência é salva (localStorage)

  3. Given nenhum vídeo selecionado When o painel de detalhes é renderizado Then mostra estado vazio com instrução "Selecione um vídeo"

  4. Given a sidebar When o usuário clica no ícone de colapsar Then a sidebar colapsa para mostrar apenas ícones And expande ao clicar novamente

  5. And existe src/app/videos/page.tsx como Server Component And existe src/components/layout/master-detail-layout.tsx And usa ResizablePanel do shadcn/ui And implementa dark mode only And responsivo: em tablet, lista sobrepõe detalhes

Dev Notes

Architecture Patterns

  • Server/Client Split: page.tsx permanece Server Component para auth check. Layout Client Component.
  • ResizablePanel: shadcn/ui component já instalado (usa react-resizable-panels)
  • Dark Mode Only: Não implementar toggle, apenas tema escuro
  • URL State: selectedVideoId virá da URL (?selected=abc123) - NÃO usar Zustand

Enforcement Rules (CRITICAL)

  1. Rule #10: selectedVideoId exclusivamente via URL, não no Zustand
  2. Rule #5: Import order: React/Next → External → Internal → Utils → Types
  3. Rule #6: File naming: kebab-case arquivos, PascalCase exports
  4. Rule #7: Test naming: it('verbo + comportamento'), co-localizados
