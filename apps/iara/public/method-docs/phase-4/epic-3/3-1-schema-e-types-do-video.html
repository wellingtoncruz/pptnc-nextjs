Story 3.1: Schema e Types do Video

Status: done

Story

Como um desenvolvedor, Eu quero schemas Zod e types TypeScript para Video, Para que os dados de vídeos sejam validados e tipados corretamente.

Context

Background

O Epic 3 (Detecção de Vídeos) inicia com a criação da camada de dados para vídeos. Esta story estabelece a fundação para todas as stories subsequentes do Epic 3 e além.

Dependências Resolvidas (Epic 1 e 2)

  • ✅ State machine de VideoStatus (Story 1-2)
  • ✅ PodcastSchema e VideoTypesConfigSchema (Story 2-1)
  • ✅ TimestampSchema reutilizável de podcast.ts
  • ✅ Estrutura de subcollections podcasts/{podcastId}/videos/{videoId}

Acceptance Criteria

AC1: VideoSchema com Campos Completos

Given a necessidade de validar dados de vídeo When eu importo os schemas de src/lib/schemas/video.ts Then tenho acesso ao VideoSchema com os campos:

  • id: string (YouTube video ID)
  • podcastId: string
  • youtubeData: { title, description, thumbnail, duration, publishedAt }
  • generatedData: { title?, description?, tags?, chapters?, compliance? }
  • status: VideoStatus
  • videoType: 'episode' | 'cut' | 'reel'
  • deleted: boolean (soft delete flag)
  • createdAt: Timestamp
  • updatedAt: Timestamp

AC2: Função classifyVideoType

Given a duração de um vídeo em segundos When eu chamo classifyVideoType(durationSeconds, config) Then retorna:

  • 'episode' se duration >= config.episode.minDuration
  • 'cut' se duration >= config.cut.minDuration E < config.episode.minDuration
  • 'reel' se duration < config.cut.minDuration

AC3: YouTubeVideoResponseSchema

Given dados do YouTube API When eu valido com YouTubeVideoResponseSchema.parse(data) Then os dados são validados e transformados para o formato interno And lança ZodError se a response for inválida

AC4: Types Inferidos

Given os schemas criados When eu importo de src/types/video.ts Then tenho acesso aos types:

  • Video - tipo completo do documento
  • VideoSummary - para lista (id, title, thumbnail, status, videoType, duration)
  • VideoDetail - para detalhe (todos os campos incluindo generatedData)
  • VideoType - union type 'episode' | 'cut' | 'reel'
  • YouTubeVideoData - dados do YouTube
  • GeneratedData - dados gerados pela IA

AC5: Testes Unitários

Given os schemas e funções criados When eu executo pnpm test Then todos os testes passam incluindo:

  • Validação de VideoSchema com dados válidos
  • Rejeição de VideoSchema com campos ausentes
  • Classificação correta de videoType pela duração
  • Parsing de ISO 8601 duration do YouTube

Schema Completo do Video

// src/lib/schemas/video.ts
import { z } from 'zod'
import { TimestampSchema } from './podcast'
import { VideoStatusSchema } from '@/lib/video-state-machine/types'

export const VideoTypeSchema = z.enum(['episode', 'cut', 'reel'])

export const ChapterSchema = z.object({
  title: z.string().min(1),
  timestamp: z.number().nonnegative(),
})

export const ComplianceItemSchema = z.object({
  risk: z.string(),
  argument: z.string(),
  timestamp: z.number().nonnegative(),
})

export const ComplianceSchema = z.object({
  status: z.enum(['ok', 'warning']),
  items: z.array(ComplianceItemSchema),
})

export const GeneratedDataSchema = z.object({
  title: z.string().optional(),
  description: z.string().optional(),
  tags: z.array(z.string()).optional(),
  chapters: z.array(ChapterSchema).optional(),
  compliance: ComplianceSchema.optional(),
})

export const YouTubeDataSchema = z.object({
  title: z.string(),
  description: z.string(),
  thumbnail: z.string().url(),
  duration: z.number().positive(), // em segundos
  publishedAt: TimestampSchema,
})

export const VideoSchema = z.object({
  id: z.string().min(1), // YouTube video ID
  podcastId: z.string().min(1),
  youtubeData: YouTubeDataSchema,
  generatedData: GeneratedDataSchema.optional(),
  status: VideoStatusSchema,
  videoType: VideoTypeSchema,
  deleted: z.boolean().default(false),
  createdAt: TimestampSchema,
  updatedAt: TimestampSchema,
})

Função parseYouTubeDuration

// src/lib/video-utils.ts

/**
 * Parses YouTube ISO 8601 duration format to seconds.
 *
 * @example
 * parseYouTubeDuration('PT1H2M3S') // 3723
 * parseYouTubeDuration('PT5M') // 300
 * parseYouTubeDuration('PT30S') // 30
 * parseYouTubeDuration('P0D') // 0 (livestream)
 */
export function parseYouTubeDuration(iso8601: string): number {
  const match = iso8601.match(/PT(?:(\d+)H)?(?:(\d+)M)?(?:(\d+)S)?/)
  if (!match) return 0

  const hours = parseInt(match[1] || '0', 10)
  const minutes = parseInt(match[2] || '0', 10)
  const seconds = parseInt(match[3] || '0', 10)

  return hours * 3600 + minutes * 60 + seconds
}

Função classifyVideoType

// src/lib/video-utils.ts
import type { VideoTypesConfig } from '@/types/podcast'
import type { VideoType } from '@/types/video'

/**
 * Classifica o tipo de vídeo baseado na duração.
 *
 * @param durationSeconds - Duração do vídeo em segundos
 * @param config - Configuração de thresholds do podcast
 * @returns 'episode' | 'cut' | 'reel'
 */
export function classifyVideoType(
  durationSeconds: number,
  config: VideoTypesConfig
): VideoType {
  if (durationSeconds >= config.episode.minDuration) {
    return 'episode'
  }
  if (durationSeconds >= config.cut.minDuration) {
    return 'cut'
  }
  return 'reel'
}

  VideoSchema,

export type YouTubeVideoData = z.infer<typeof YouTubeDataSchema>
export type GeneratedData = z.infer<typeof GeneratedDataSchema>

  title: string // youtubeData.title
  thumbnail: string // youtubeData.thumbnail
  duration: number // youtubeData.duration
}

/**
 * VideoDetail - todos os campos para exibição detalhada.
 * Usado no VideoDetailPanel component.

export type VideoDetail = Video

YouTube API Response Schema

// src/lib/schemas/youtube-api.ts

/**
 * Schema para validar response da YouTube Data API v3.
 * Endpoint: videos.list?part=snippet,contentDetails
 */
export const YouTubeVideoItemSchema = z.object({
  id: z.string(),
  snippet: z.object({
    title: z.string(),
    description: z.string(),
    thumbnails: z.object({
      medium: z.object({ url: z.string().url() }),
      high: z.object({ url: z.string().url() }).optional(),
    }),
    publishedAt: z.string().datetime(),
  }),
  contentDetails: z.object({
    duration: z.string(), // ISO 8601: PT1H2M3S
  }),
})

export const YouTubeVideosResponseSchema = z.object({
  items: z.array(YouTubeVideoItemSchema),
  nextPageToken: z.string().optional(),
})

Testes Table-Driven para classifyVideoType

// src/lib/video-utils.test.ts
import { describe, it, expect } from 'vitest'
import { classifyVideoType, parseYouTubeDuration } from './video-utils'
import { DEFAULT_VIDEO_TYPES } from '@/lib/schemas/podcast'

describe('parseYouTubeDuration', () => {
  it.each([
    ['PT1H2M3S', 3723],
    ['PT5M', 300],
    ['PT30S', 30],
    ['PT1H', 3600],
    ['PT1H30M', 5400],
    ['P0D', 0],
    ['', 0],
  ])('parses %s to %d seconds', (input, expected) => {
    expect(parseYouTubeDuration(input)).toBe(expected)
  })
})

describe('classifyVideoType', () => {
  const config = DEFAULT_VIDEO_TYPES

  it.each([
    [1200, 'episode'],   // exactly minDuration
    [3600, 'episode'],   // 1 hour
    [1199, 'cut'],       // just below episode threshold
    [180, 'cut'],        // exactly cut minDuration
    [179, 'reel'],       // just below cut threshold
    [60, 'reel'],        // 1 minute
    [0, 'reel'],         // edge case
  ])('classifies %d seconds as %s', (duration, expected) => {
    expect(classifyVideoType(duration, config)).toBe(expected)
  })
})
