Story 3.2: Integração YouTube Data API para Listar Vídeos

Status: done

Story

Como um sistema, Eu quero buscar vídeos do canal do usuário via YouTube Data API, Para que novos uploads sejam detectados automaticamente.

Context

Background

Esta story implementa a integração com YouTube Data API v3 para listar vídeos do canal configurado. É a segunda story do Epic 3 (Detecção de Vídeos) e depende dos schemas criados na Story 3-1.

YouTube API Flow

A YouTube Data API requer uma sequência específica de chamadas:

1. channels.list?mine=true&part=contentDetails
   → Retorna o uploads playlist ID (relatedPlaylists.uploads)

2. playlistItems.list?playlistId={uploadsId}&part=snippet
   → Retorna lista de vídeos do canal (com videoId)

3. videos.list?id={videoIds}&part=snippet,contentDetails
   → Retorna detalhes completos (duration, publishedAt)

Acceptance Criteria

AC1: Endpoint de Listar Vídeos

Given um usuário autenticado com token YouTube válido When eu chamo GET /api/youtube/videos Then retorna lista de vídeos do canal do usuário And cada vídeo contém: id, title, description, thumbnail, duration, publishedAt And os dados são validados com Zod ANTES de retornar

AC2: Token Refresh Automático

Given um token expirado When a requisição é feita Then o token é renovado automaticamente via refresh_token And a requisição é retentada com o novo token

AC3: Tratamento de Erro - Quota

Given quota do YouTube excedida When a API retorna erro 403 (quotaExceeded) Then retorna { error: { code: 'YOUTUBE_QUOTA', message: '...' } } And o erro é logado via structured logging

AC4: Tratamento de Erro - Não Encontrado

Given canal/vídeo não encontrado ou privado When a API retorna erro 404 Then retorna { error: { code: 'YOUTUBE_NOT_FOUND', message: '...' } }

AC5: Tratamento de Erro - Forbidden

Given usuário sem permissão no canal When a API retorna erro 403 (forbidden) Then retorna { error: { code: 'YOUTUBE_FORBIDDEN', message: '...' } }

AC6: Paginação

Given um canal com muitos vídeos (> 50) When a requisição é feita Then implementa paginação via pageToken And query param opcional ?maxResults=N limita quantidade (default 50, max 50)

AC7: YouTubeClient Wrapper

Given a necessidade de chamadas à YouTube API When eu uso YouTubeClient Then centraliza autenticação, retry (somente leituras), e error handling And inclui logging estruturado para todas as operações

YouTubeClient Wrapper

// src/lib/youtube/client.ts
import { log } from '@/lib/logger'
import {
  YouTubeChannelsResponseSchema,
  YouTubePlaylistItemsResponseSchema,
  YouTubeVideosResponseSchema,
} from '@/lib/schemas/youtube-api'
import { parseYouTubeDuration } from '@/lib/video-utils'
import type { YouTubeVideoData } from '@/types/video'

const YOUTUBE_API_BASE = 'https://www.googleapis.com/youtube/v3'
const MAX_RETRY_ATTEMPTS = 3
const BACKOFF_BASE = 1000

type ErrorCode =
  | 'YOUTUBE_QUOTA'
  | 'YOUTUBE_NOT_FOUND'
  | 'YOUTUBE_FORBIDDEN'
  | 'YOUTUBE_ERROR'
  | 'YOUTUBE_INVALID_RESPONSE'

export class YouTubeAPIError extends Error {
  constructor(
    public code: ErrorCode,
    message: string,
    public status?: number
  ) {
    super(message)
    this.name = 'YouTubeAPIError'
  }
}

export class YouTubeClient {
  constructor(private accessToken: string) {}

  private async fetch<T>(
    endpoint: string,
    schema: z.ZodSchema<T>,
    retries = MAX_RETRY_ATTEMPTS
  ): Promise<T> {
    const url = `${YOUTUBE_API_BASE}${endpoint}`

    for (let attempt = 0; attempt < retries; attempt++) {
      try {
        const response = await fetch(url, {
          headers: {
            Authorization: `Bearer ${this.accessToken}`,
            Accept: 'application/json',
          },
        })

        if (!response.ok) {
          await this.handleErrorResponse(response)
        }

        const data = await response.json()
        return schema.parse(data)
      } catch (error) {
        if (error instanceof YouTubeAPIError) throw error
        if (error instanceof z.ZodError) {
          log('ERROR', 'YouTube API response validation failed', { error, endpoint })
          throw new YouTubeAPIError('YOUTUBE_INVALID_RESPONSE', 'Invalid response format')
        }

        // Retry on network errors
        if (attempt < retries - 1) {
          const delay = BACKOFF_BASE * Math.pow(2, attempt)
          await new Promise(resolve => setTimeout(resolve, delay))
          continue
        }
        throw error
      }
    }

    throw new Error('Unreachable')
  }

  private async handleErrorResponse(response: Response): Promise<never> {
    const body = await response.json().catch(() => ({}))
    const reason = body?.error?.errors?.[0]?.reason

    log('WARNING', 'YouTube API error', { status: response.status, reason, body })

    if (response.status === 403) {
      if (reason === 'quotaExceeded') {
        throw new YouTubeAPIError('YOUTUBE_QUOTA', 'YouTube API quota exceeded', 403)
      }
      throw new YouTubeAPIError('YOUTUBE_FORBIDDEN', 'Access forbidden', 403)
    }

    if (response.status === 404) {
      throw new YouTubeAPIError('YOUTUBE_NOT_FOUND', 'Resource not found', 404)
    }

    throw new YouTubeAPIError('YOUTUBE_ERROR', `YouTube API error: ${response.status}`, response.status)
  }

  async getUploadsPlaylistId(): Promise<string> {
    const data = await this.fetch(
      '/channels?mine=true&part=contentDetails',
      YouTubeChannelsResponseSchema
    )

    if (!data.items.length) {
      throw new YouTubeAPIError('YOUTUBE_NOT_FOUND', 'No channel found for user')
    }

    return data.items[0].contentDetails.relatedPlaylists.uploads
  }

  async listPlaylistItems(
    playlistId: string,
    maxResults = 50,
    pageToken?: string
  ): Promise<{ videoIds: string[], nextPageToken?: string }> {
    let endpoint = `/playlistItems?playlistId=${playlistId}&part=snippet&maxResults=${maxResults}`
    if (pageToken) endpoint += `&pageToken=${pageToken}`

    const data = await this.fetch(endpoint, YouTubePlaylistItemsResponseSchema)

    const videoIds = data.items.map(item => item.snippet.resourceId.videoId)
    return { videoIds, nextPageToken: data.nextPageToken }
  }

  async getVideoDetails(videoIds: string[]): Promise<YouTubeVideoData[]> {
    if (videoIds.length === 0) return []

    const ids = videoIds.join(',')
    const data = await this.fetch(
      `/videos?id=${ids}&part=snippet,contentDetails`,
      YouTubeVideosResponseSchema
    )

    return data.items.map(item => ({
      id: item.id,
      title: item.snippet.title,
      description: item.snippet.description,
      thumbnail: item.snippet.thumbnails.medium?.url
        || item.snippet.thumbnails.high?.url
        || '',
      duration: parseYouTubeDuration(item.contentDetails.duration),
      publishedAt: item.snippet.publishedAt,
    }))
  }

  async listVideos(
    maxResults = 50,
    pageToken?: string
  ): Promise<{ videos: YouTubeVideoData[], nextPageToken?: string }> {
    log('INFO', 'Listing YouTube videos', { maxResults, pageToken })

    const uploadsPlaylistId = await this.getUploadsPlaylistId()
    const { videoIds, nextPageToken } = await this.listPlaylistItems(
      uploadsPlaylistId,
      maxResults,
      pageToken
    )

    const videos = await this.getVideoDetails(videoIds)

    log('INFO', 'YouTube videos listed', { count: videos.length, hasMore: !!nextPageToken })
    return { videos, nextPageToken }
  }
}

Route Handler Template

// src/app/api/youtube/videos/route.ts
import { NextRequest, NextResponse } from 'next/server'
import { getServerSession } from '@/lib/auth'
import { log } from '@/lib/logger'
import { YouTubeClient, YouTubeAPIError } from '@/lib/youtube/client'
import { getUserTokens, refreshUserToken } from '@/lib/firebase/tokens'
import { PODCAST_ID } from '@/lib/firebase/config'

export const runtime = 'nodejs'

export async function GET(request: NextRequest) {
  const session = await getServerSession()
  if (!session?.user?.id) {
    return NextResponse.json(
      { error: { code: 'AUTH_EXPIRED', message: 'Sessão expirada' } },
      { status: 401 }
    )
  }

  try {
    // Get query params
    const { searchParams } = new URL(request.url)
    const maxResults = Math.min(parseInt(searchParams.get('maxResults') || '50'), 50)
    const pageToken = searchParams.get('pageToken') || undefined

    // Get user tokens
    let tokens = await getUserTokens(session.user.id, PODCAST_ID)

    // Refresh if expired
    if (tokens.needsRefresh) {
      tokens = await refreshUserToken(session.user.id, PODCAST_ID, tokens.refreshToken)
    }

    // Call YouTube API
    const client = new YouTubeClient(tokens.accessToken)
    const result = await client.listVideos(maxResults, pageToken)

    return NextResponse.json({ data: result })
  } catch (error) {
    if (error instanceof YouTubeAPIError) {
      log('WARNING', 'YouTube API error in list videos', { code: error.code, message: error.message })
      return NextResponse.json(
        { error: { code: error.code, message: error.message } },
        { status: error.status || 500 }
      )
    }

    log('ERROR', 'Unexpected error listing YouTube videos', { error })
    return NextResponse.json(
      { error: { code: 'INTERNAL_ERROR', message: 'Erro interno ao buscar vídeos' } },
      { status: 500 }
    )
  }
}

Token Helper

// src/lib/firebase/tokens.ts
import { adminDb } from './admin'
import { PODCAST_ID } from './config'
import { log } from '@/lib/logger'
import { z } from 'zod'

const TokensSchema = z.object({
  accessToken: z.string(),
  refreshToken: z.string(),
  expiresAt: z.number(),
})

export type UserTokens = z.infer<typeof TokensSchema> & {
  needsRefresh: boolean
}

export async function getUserTokens(userId: string, podcastId: string): Promise<UserTokens> {
  const docRef = adminDb
    .collection('podcasts')
    .doc(podcastId)
    .collection('users')
    .doc(userId)
    .collection('tokens')
    .doc('oauth')

  const doc = await docRef.get()

  if (!doc.exists) {
    throw new Error('No tokens found for user')
  }

  const data = TokensSchema.parse(doc.data())
  const needsRefresh = Date.now() > (data.expiresAt - 5 * 60 * 1000) // 5 min buffer

  return { ...data, needsRefresh }
}

export async function refreshUserToken(
  userId: string,
  podcastId: string,
  refreshToken: string
): Promise<UserTokens> {
  // Call Google OAuth token endpoint
  const response = await fetch('https://oauth2.googleapis.com/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      client_id: process.env.GOOGLE_CLIENT_ID!,
      client_secret: process.env.GOOGLE_CLIENT_SECRET!,
      refresh_token: refreshToken,
      grant_type: 'refresh_token',
    }),
  })

  if (!response.ok) {
    log('ERROR', 'Token refresh failed', { status: response.status })
    throw new Error('Failed to refresh token')
  }

  const data = await response.json()
  const expiresAt = Date.now() + data.expires_in * 1000

  // Update Firestore (preserve refresh_token)
  const docRef = adminDb
    .collection('podcasts')
    .doc(podcastId)
    .collection('users')
    .doc(userId)
    .collection('tokens')
    .doc('oauth')

  await docRef.update({
    accessToken: data.access_token,
    expiresAt,
    updatedAt: FieldValue.serverTimestamp(),
    // ⚠️ NUNCA sobrescrever refreshToken
  })

  log('INFO', 'Token refreshed successfully', { userId })

  return {
    accessToken: data.access_token,
    refreshToken, // Mantém o original
    expiresAt,
    needsRefresh: false,
  }
}
