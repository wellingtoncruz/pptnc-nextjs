Story 3.5: Componente VideoListItem

Status: done

Story

As a usuário, I want ver meus vídeos em uma lista visual com status, so that eu possa identificar rapidamente o estado de cada vídeo.

Acceptance Criteria

  1. Given a lista de vídeos carregada When eu visualizo um item Then vejo:

    • Thumbnail do vídeo (aspect ratio 16:9)
    • Título (truncado se muito longo)
    • Badge de status colorido
    • Badge de tipo (episódio/corte/reel)

  2. Given os status possíveis When renderizo os badges Then as cores são:

    • new: gray
    • processing: blue (com animação pulse)
    • draft: yellow
    • ready: green
    • sending: blue (com animação)
    • sent: green (check icon)

  3. Given um vídeo na lista When eu clico nele Then o vídeo é selecionado And a URL atualiza para ?selected={videoId} (URL state) And o item recebe estilo de seleção (ring-blue-400)

  4. Given a lista de vídeos When eu pressiono ↓ ou ↑ Then a seleção move para o próximo/anterior vídeo And a URL é atualizada And o scroll acompanha a seleção

  5. Given um vídeo selecionado When eu pressiono Enter Then o foco vai para o painel de detalhes

  6. And existe src/components/videos/video-list-item.tsx And usa Badge do shadcn/ui para status And implementa role="listbox" e role="option" para a11y And usa useSearchParams para URL state (enforcement rule #10)

Dev Notes

Architecture Patterns

  • URL State: selectedVideoId NUNCA no Zustand, sempre via URL param ?selected= (Rule #10)
  • Component Location: src/components/videos/video-list-item.tsx
  • Styling: Dark mode only, usar Tailwind classes
  • Badges: Usar Badge do shadcn/ui (já instalado)

Enforcement Rules (CRITICAL)

  1. Rule #10: selectedVideoId exclusivamente via URL, não no Zustand
  2. Rule #5: Import order: React/Next → External → Internal → Utils → Types
  3. Rule #6: File naming: kebab-case arquivos, PascalCase exports
  4. Rule #7: Test naming: it('verbo + comportamento'), co-localizados
  5. Rule #11: Usar import type quando import é apenas type annotation

Keyboard Navigation Pattern

// In VideoListPanel or parent component
const handleKeyDown = (e: KeyboardEvent) => {
  if (e.key === 'ArrowDown') {
    e.preventDefault()
    selectNext()
  } else if (e.key === 'ArrowUp') {
    e.preventDefault()
    selectPrevious()
  } else if (e.key === 'Enter') {
    e.preventDefault()
    focusDetailPanel()
  }
}

describe('VideoListItem', () => {
  it('renderiza thumbnail, título e badges', () => {
    render(<VideoListItem video={mockVideo} isSelected={false} onSelect={vi.fn()} />)
    expect(screen.getByRole('img')).toHaveAttribute('alt', mockVideo.title)
    expect(screen.getByText(mockVideo.title)).toBeInTheDocument()
  })

  it('aplica estilo de seleção quando isSelected', () => {
    render(<VideoListItem video={mockVideo} isSelected={true} onSelect={vi.fn()} />)
    expect(screen.getByRole('option')).toHaveClass('ring-blue-400')
  })

  it('chama onSelect com videoId ao clicar', async () => {
    const onSelect = vi.fn()
    const user = userEvent.setup()
    render(<VideoListItem video={mockVideo} isSelected={false} onSelect={onSelect} />)
    await user.click(screen.getByRole('option'))
    expect(onSelect).toHaveBeenCalledWith(mockVideo.id)
  })
})
