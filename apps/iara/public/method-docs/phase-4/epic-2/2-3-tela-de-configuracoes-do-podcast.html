Story 2.3: Tela de Configurações do Podcast

Status: done

Story

Como um usuário, Eu quero acessar uma tela de configurações do meu podcast, Para que eu possa visualizar e editar as configurações atuais.

Acceptance Criteria

AC1: Navegação para Configurações

Given um usuário autenticado When ele clica em "Configurações" na sidebar Then navega para /settings And vê o formulário de configurações do podcast

AC2: Carregamento de Dados

Given a tela de configurações carregada When os dados do podcast são buscados Then os campos são preenchidos com valores atuais:

  • Nome do podcast
  • Channel ID do YouTube And mostra skeleton enquanto carrega

AC3: Edição com Auto-Save

Given um usuário edita o nome do podcast When ele sai do campo (blur) ou aguarda 1.5s após parar de digitar Then a alteração é salva automaticamente And vê indicador "Salvando..." durante a operação And vê indicador "Salvo" confirmando a operação

AC4: Tratamento de Erros

Given um erro ao salvar When a operação de update falha Then vê indicador "Erro ao salvar" em vermelho And o erro é logado via structured logging (log()) And o valor editado é preservado localmente

AC5: Validação de Campos

Given campos de configuração When o usuário tenta salvar valores inválidos Then validação Zod é executada no client And erros de validação são exibidos inline And a operação de save é bloqueada

AC6: Link na Sidebar

Given a sidebar do aplicativo When renderizada Then exibe link para /settings com ícone de engrenagem (Settings do lucide-react) And link mostra estado ativo quando na página de configurações

// src/app/settings/page.tsx
import { Suspense } from 'react'

import { getPodcastAdmin } from '@/lib/firebase/podcasts-admin'
import { PODCAST_ID } from '@/lib/firebase/config'
import { PodcastSettingsForm } from '@/components/settings/podcast-settings-form'
import { Skeleton } from '@/components/ui/skeleton'

export default async function SettingsPage() {
  const podcast = await getPodcastAdmin(PODCAST_ID)

  if (!podcast) {
    return <div>Podcast não encontrado</div>
  }

  return (
    <div className="container max-w-2xl py-8">
      <h1 className="text-2xl font-bold mb-6">Configurações</h1>
      <Suspense fallback={<SettingsFormSkeleton />}>
        <PodcastSettingsForm podcast={podcast} />
      </Suspense>
    </div>
  )
}

function SettingsFormSkeleton() {
  return (
    <div className="space-y-4">
      <Skeleton className="h-10 w-full" />
      <Skeleton className="h-10 w-full" />
    </div>
  )
}

Padrão de Implementação - Client Component

// src/components/settings/podcast-settings-form.tsx
'use client'

import { useState } from 'react'

import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'
import { Input } from '@/components/ui/input'
import { Label } from '@/components/ui/label'
import { useAutoSave } from '@/hooks/use-auto-save'
import { updatePodcast } from '@/lib/firebase/podcasts'
import { PodcastUpdateSchema } from '@/lib/schemas'
import { log } from '@/lib/logger'
import type { Podcast } from '@/types/podcast'

interface PodcastSettingsFormProps {
  podcast: Podcast
}

export function PodcastSettingsForm({ podcast }: PodcastSettingsFormProps) {
  const [name, setName] = useState(podcast.name)

  const { saveStatus, error } = useAutoSave(
    name,
    async (value) => {
      const validated = PodcastUpdateSchema.parse({ name: value })
      await updatePodcast(podcast.id, validated)
    },
    1500
  )

  return (
    <Card>
      <CardHeader>
        <CardTitle>Informações do Podcast</CardTitle>
      </CardHeader>
      <CardContent className="space-y-4">
        <div className="space-y-2">
          <Label htmlFor="name">Nome do Podcast</Label>
          <Input
            id="name"
            value={name}
            onChange={(e) => setName(e.target.value)}
          />
          <SaveStatusIndicator status={saveStatus} error={error} />
        </div>

        <div className="space-y-2">
          <Label htmlFor="channelId">Channel ID do YouTube</Label>
          <Input
            id="channelId"
            value={podcast.channelId}
            disabled
            className="bg-muted"
          />
          <p className="text-xs text-muted-foreground">
            O Channel ID não pode ser alterado
          </p>
        </div>
      </CardContent>
    </Card>
  )
}

function SaveStatusIndicator({
  status,
  error
}: {
  status: 'idle' | 'saving' | 'saved' | 'error'
  error: Error | null
}) {
  if (status === 'saving') {
    return <p className="text-xs text-muted-foreground">Salvando...</p>
  }
  if (status === 'saved') {
    return <p className="text-xs text-green-500">Salvo</p>
  }
  if (status === 'error') {
    return <p className="text-xs text-red-500">Erro ao salvar</p>
  }
  return null
}

Padrão de Implementação - useAutoSave Hook

// src/hooks/use-auto-save.ts
'use client'

import { useCallback, useEffect, useRef, useState } from 'react'

import { log } from '@/lib/logger'

type SaveStatus = 'idle' | 'saving' | 'saved' | 'error'

interface UseAutoSaveReturn {
  saveStatus: SaveStatus
  error: Error | null
  save: () => void
}

export function useAutoSave<T>(
  value: T,
  saveFn: (value: T) => Promise<void>,
  delay: number = 1500
): UseAutoSaveReturn {
  const [saveStatus, setSaveStatus] = useState<SaveStatus>('idle')
  const [error, setError] = useState<Error | null>(null)
  const timeoutRef = useRef<NodeJS.Timeout | null>(null)
  const lastSavedValueRef = useRef<T>(value)
  const isMountedRef = useRef(true)

  const performSave = useCallback(async (valueToSave: T) => {
    if (valueToSave === lastSavedValueRef.current) return

    setSaveStatus('saving')
    setError(null)

    try {
      await saveFn(valueToSave)
      if (isMountedRef.current) {
        lastSavedValueRef.current = valueToSave
        setSaveStatus('saved')
        // Reset to idle after 2s
        setTimeout(() => {
          if (isMountedRef.current) {
            setSaveStatus('idle')
          }
        }, 2000)
      }
    } catch (err) {
      if (isMountedRef.current) {
        const error = err instanceof Error ? err : new Error(String(err))
        setError(error)
        setSaveStatus('error')
        log('ERROR', 'Auto-save failed', { error })
      }
    }
  }, [saveFn])

  // Debounced save on value change
  useEffect(() => {
    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current)
    }

    timeoutRef.current = setTimeout(() => {
      performSave(value)
    }, delay)

    return () => {
      if (timeoutRef.current) {
        clearTimeout(timeoutRef.current)
      }
    }
  }, [value, delay, performSave])

  // Cleanup on unmount
  useEffect(() => {
    isMountedRef.current = true
    return () => {
      isMountedRef.current = false
    }
  }, [])

  // Force immediate save
  const save = useCallback(() => {
    if (timeoutRef.current) {
      clearTimeout(timeoutRef.current)
    }
    performSave(value)
  }, [value, performSave])

  return { saveStatus, error, save }
}

Enforcement Rules Aplicáveis

  1. Rule #2 (Zod Validation): Validar com PodcastUpdateSchema.parse() ANTES de chamar updatePodcast()
  2. Rule #4 (Field-Level Updates): updatePodcast() já usa updateDoc, não setDoc
  3. Rule #6 (File Naming): kebab-case para arquivos, PascalCase para exports
  4. Rule #9 (Structured Logging): Usar log() para erros, nunca console.log
  5. Rule #11 (Import Type): Usar import type para Podcast
  6. Rule #12 (Timestamp SDK): Client Component usa serverTimestamp() via updatePodcast()
