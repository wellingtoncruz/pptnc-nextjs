Story 5.1: Melhorias de Layout do Wizard

Status: done

Story

As a produtor, I want uma interface mais informativa e intuitiva no wizard, so that eu tenha melhor visibilidade do video sendo processado e feedback visual claro durante operacoes.

Acceptance Criteria

  1. AC1: Titulo do Video Acima do Player

    • Given o Wizard aberto com um video selecionado
    • When a pagina e renderizada
    • Then o titulo do video (video.title ou titulo original do YouTube) aparece acima do player
    • And usa tipografia destacada (h2 ou similar)

  2. AC2: Metadados Abaixo do Player

    • Given o Wizard aberto com um video selecionado
    • When a pagina e renderizada
    • Then abaixo do player exibe:
      • Data de criacao (video.publishedAt)
      • Data da ultima atualizacao (video.updatedAt)
      • Duracao do video formatada (HH:MM:SS)
    • And layout compacto em linha unica

  3. AC3: Spinner Visual Durante Processamento LLM

    • Given uma fase que depende de processamento LLM
    • When o processamento ainda nao iniciou ou esta em andamento
    • Then a Area de Interatividade mostra um spinner grafico proeminente
    • And o spinner ocupa boa parte da area disponivel (minimo 200px altura)
    • And substitui a mensagem de texto "O processamento iniciara automaticamente."

  4. AC4: Botao Avancar com Nome da Fase

    • Given qualquer fase do wizard com botao de avancar
    • When o botao e renderizado
    • Then texto do botao e "Avancar para [Nome da Fase]"
    • And nomes das fases:
      • Fase 2: "Analise de Edicao"
      • Fase 3: "Risco e Conformidade"
      • Fase 4: "Capitulos"
      • Fase 5: "Titulo"
      • Fase 6: "Descricao"
      • Fase 7: "Tags"
      • Fase 8: "Publicar no YouTube"

  5. AC5: Alertas Colapsaveis no Console

    • Given multiplos alertas/spinners na Console Area
    • When um novo item e adicionado ou atualizado
    • Then os demais itens colapsam automaticamente
    • And apenas o item atual fica expandido/em evidencia
    • And usuario pode expandir/colapsar manualmente clicando no item

PHASE_NAMES Map

// src/lib/wizard/phase-names.ts
import type { WizardPhase } from './types'

export const PHASE_NAMES: Record<WizardPhase, string> = {
  1: 'Critica Inicial',
  2: 'Analise de Edicao',
  3: 'Risco e Conformidade',
  4: 'Capitulos',
  5: 'Titulo',
  6: 'Descricao',
  7: 'Tags',
  8: 'Publicar no YouTube',
}

export function getNextPhaseName(currentPhase: WizardPhase): string | null {
  const nextPhase = currentPhase < 8 ? (currentPhase + 1) as WizardPhase : null
  return nextPhase ? PHASE_NAMES[nextPhase] : null
}

Padrao de Formatacao de Data

Usar date-fns com locale pt-BR:

import { format } from 'date-fns'
import { ptBR } from 'date-fns/locale'

// Para publishedAt
format(new Date(video.publishedAt), "dd MMM yyyy", { locale: ptBR })

// Para updatedAt (com hora)
format(video.updatedAt.toDate(), "dd MMM yyyy 'as' HH:mm", { locale: ptBR })

// Para duracao (segundos -> HH:MM:SS)
function formatDuration(seconds: number): string {
  const h = Math.floor(seconds / 3600)
  const m = Math.floor((seconds % 3600) / 60)
  const s = seconds % 60
  return `${h.toString().padStart(2, '0')}:${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`
}

Logica de Auto-Colapso no Console

// Em useWizard.ts - modificar addAlert
const addAlert = useCallback(
  (phase, title, text, severity = 'info') => {
    const messageId = `${idPrefix}-alert-${phase}-${++messageCounter.current}`

    setConsoleMessages((prev) => {
      // Colapsa todos os items anteriores
      const collapsedPrev = prev.map(m => ({ ...m, collapsed: true }))

      const message: ConsoleMessage = {
        id: messageId,
        phase,
        type: 'alert',
        timestamp: new Date(),
        alertTitle: title,
        alertText: text,
        alertSeverity: severity,
        collapsed: false,  // Novo item expandido
      }

      return [...collapsedPrev, message]
    })

    return messageId
  },
  [idPrefix]
)
