Story 1.2: Fase 0 - Seleção de Vídeo Pai

Status: ready-for-dev

Story

As a produtor de conteúdo, I want selecionar o episódio "pai" que originou um vídeo cut ou reel, so that o wizard possa herdar automaticamente os campos guests e theme do episódio pai.

Acceptance Criteria

AC1: Renderização condicional da Fase 0

DADO um vídeo do tipo 'cut' ou 'reel'
QUANDO o wizard carregar
ENTÃO a Fase 0 (Seleção de Pai) deve ser exibida como primeira fase
E as fases 1-4 NÃO devem aparecer no breadcrumb

DADO um vídeo do tipo 'episode'
QUANDO o wizard carregar
ENTÃO a Fase 0 NÃO deve existir
E o fluxo deve começar na Fase 1 normalmente

AC2: Listagem de episódios disponíveis

DADO que estou na Fase 0
QUANDO a fase carregar
ENTÃO devo ver uma lista de vídeos do tipo 'episode'
E a lista deve estar ordenada por data de criação decrescente
E cada item deve mostrar:
  - Thumbnail do vídeo
  - Título do vídeo
  - Data de publicação

AC3: Seleção de episódio pai

DADO a lista de episódios
QUANDO eu clicar em um episódio
ENTÃO ele deve ser marcado como selecionado visualmente
E o botão "Avançar" deve ser habilitado

AC4: Herança de campos do pai

DADO que selecionei um episódio pai
QUANDO eu clicar em "Avançar"
ENTÃO o campo parentEpisodeId deve ser persistido no vídeo atual
E os campos guests e theme devem ser copiados do pai para o vídeo atual
E devo avançar para a Fase 5 (Título)

AC5: Alteração de pai

DADO que já tenho um pai selecionado
QUANDO eu voltar para a Fase 0 e selecionar outro pai
ENTÃO o parentEpisodeId deve ser atualizado
E os campos guests e theme devem ser atualizados com os do novo pai

AC6: Pai já selecionado (retorno)

DADO que o vídeo já tem parentEpisodeId definido
QUANDO eu abrir o wizard
ENTÃO a Fase 0 deve mostrar o pai atual como selecionado
E devo poder prosseguir sem re-selecionar

AC7: Estado de loading e erro

DADO que estou carregando a lista de episódios
QUANDO a requisição estiver em andamento
ENTÃO devo ver um indicador de loading

DADO que ocorreu um erro ao carregar
QUANDO a requisição falhar
ENTÃO devo ver uma mensagem de erro
E um botão para tentar novamente

    • 1.3: Ordenar por publishedAt DESC
    • 1.4: Retornar campos: id, title, thumbnails, publishedAt, guests, theme

    • 2.2: Validar que o vídeo atual é cut ou reel

Dev Notes

REGRA DE OURO - CRÍTICA

O fluxo de episode NÃO PODE ser modificado. Esta story adiciona funcionalidade APENAS para cut/reel:

  • Novas APIs que só são usadas por cut/reel
  • Novos componentes que só renderizam para cut/reel
  • Branching condicional baseado em video.videoType

Dependências da Story 1.1

Esta story depende da infraestrutura criada na Story 1.1:

  • PHASES_BY_VIDEO_TYPE - para determinar fases válidas
  • getPhasesForVideoType() - para obter fases por tipo
  • EXTENDED_PHASE_METADATA - para metadata da fase 0
  • ExtendedWizardPhase - tipo que inclui fase 0

Padrões de Código

  1. APIs: Seguir padrão existente em /api/videos/[videoId]/
  2. Componentes: Seguir padrão de phases em /components/wizard/phases/
  3. Fetch: Usar useSWR para data fetching com cache
  4. State: Estado local com useState para seleção

Navegação Após Seleção

Quando o pai é selecionado e "Avançar" é clicado:

  1. Persistir parentEpisodeId, guests, theme via PUT API
  2. Chamar wizard.goToPhase(5) para ir para Título
