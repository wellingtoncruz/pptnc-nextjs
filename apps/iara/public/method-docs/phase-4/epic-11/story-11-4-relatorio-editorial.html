Story 11.4: Relatório Editorial

Status: done

Story

As a produtor de conteudo, I want uma pagina publica de relatorio editorial consolidando episodio, cortes e reels, so that eu possa compartilhar o relatorio com editores, convidados e patrocinadores sem exigir login na plataforma.

Acceptance Criteria

  1. AC1 - Rota Publica: Given a URL /report/{videoId}, When qualquer usuario (autenticado ou nao) acessa, Then a pagina carrega sem exigir login, And exibe o relatorio editorial completo do episodio.

  2. AC2 - Validacao de Video: Given um videoId invalido ou de um video que nao e do tipo episode, When a pagina e acessada, Then exibe pagina 404 adequada.

  3. AC3 - Data Fetching Server-Side: Given um videoId valido de um episodio, When a pagina carrega, Then busca server-side: o video episodio, o podcast (para youtubeFooter), os guests do video, e todos os videos filhos (cuts e reels via parentEpisodeId).

  4. AC4 - Secao do Episodio: Given o relatorio renderizado, When exibido, Then mostra:

    • Titulo do episodio como heading principal (h1)
    • Separador visual
    • Critica (video.critique) em bloco destacado
    • Separador visual
    • Descricao (video.description)

  5. AC5 - Cards de Guests: Given o episodio possui guests, When renderizado, Then:

    • Todos os convidados apresentados igualmente em grid 2 colunas
    • Cada card: avatar grande (size-24) com link direto para foto (nova aba), nome, role/company, link LinkedIn
    • Se guest nao tem photo, exibe placeholder com iniciais

  6. AC6 - Capitulos: Given o episodio possui chapters, When renderizado, Then exibe lista de capitulos: timestamp em font-mono com cor muted, titulo ao lado.

  7. AC7 - YouTube Footer e Tags do Episodio: Given o relatorio renderizado, When exibido, Then mostra podcast.youtubeFooter (se existir) seguido das tags como chips/badges inline.

  8. AC8 - Secao de Cortes (Cuts): Given o episodio possui videos filhos do tipo cut, When renderizado, Then para cada corte exibe:

    • Titulo como h2
    • Badge/chip com shortTitle (titulo curto para thumbnail) estilizado
    • Descricao do corte
    • podcast.youtubeFooter
    • Tags como chips/badges
    • Separador entre cada corte

  9. AC9 - Secao de Reels: Given o episodio possui videos filhos do tipo reel, When renderizado, Then para cada reel exibe:

    • Titulo como h2
    • Descricao do reel
    • podcast.youtubeFooter
    • Tags como chips/badges
    • Separador entre cada reel

  10. AC10 - Layout Print-Friendly: Given a pagina de relatorio, When renderizada, Then:

    • Layout centralizado com largura maxima adequada para impressao (~800px / max-w-3xl)
    • CSS @media print que esconde elementos de navegacao e otimiza page breaks
    • Tipografia com boa legibilidade e espacamento generoso

  11. AC11 - Botao na Editorial: Given o card de episodio na secao Editorial, When o episodio possui dados suficientes, Then o botao "Relatorio Editorial" esta habilitado e abre /report/{videoId} em nova aba (target="_blank").

Decisoes Tecnicas

  • Rota: /report/[videoId] com path param (nao query string) — URL limpa para compartilhar
  • Auth: Rota 100% publica. Dados exibidos sao semi-publicos (destinados ao YouTube)
  • Server Component: Fetch direto com Admin SDK, zero client-side fetch, HTML puro no cliente
  • Guests inline: Usar video.guests[] diretamente (ja estao no doc do video), sem join com subcollection
  • Print: CSS @media print nativo, sem biblioteca PDF
  • Podcast ID: Extrair do video.podcastId para buscar podcast (youtubeFooter)
