Product Requirements Document - IAra

Author: Wellington Date: 2026-01-23

Executive Summary

O IAra é uma plataforma web de gestão do pipeline de publicação de vídeos para o podcast PPT Não Compila. Automatiza a geração de metadados otimizados para SEO do YouTube (título, descrição, índice de capítulos, tags) e verificação de compliance, utilizando LLM (Gemini) com prompts especializados baseados em know-how real de produção de podcasts.

Problema: Um único produtor gerencia manualmente ~22 vídeos por semana (episódios, cortes e reels), com processo artesanal de copiar/colar entre browser, LLMs e plataformas. A geração de metadados de qualidade é o principal gargalo — impacta cadência, qualidade de SEO e verificação de compliance.

Solução: Pipeline integrado em 3 passos — detectar novos vídeos via YouTube API, processar metadados via Gemini com prompts especializados por tipo de vídeo, e finalizar com envio em lote para YouTube via API. Interface simples para usuário não técnico, com rascunhos persistentes e capacidade de iteração (reprocessar com instruções adicionais).

Proposta de Valor: Consistência em escala com redução de carga cognitiva — o produtor resolve toda a semana de publicações em uma única sessão, com metadados otimizados para SEO e compliance verificado automaticamente. O LLM não cansa, não pula capítulos, não esquece tags. Qualidade uniforme em 22 vídeos/semana sem esforço proporcional.

What Makes This Special

  • SEO-first: Metadados gerados com foco em otimização para YouTube Search e discoverability, não apenas descritivos
  • Consistência em escala: Qualidade uniforme de metadados em alto volume — o LLM mantém o padrão que um humano sozinho não consegue sustentar
  • Redução de carga cognitiva: Produtor não precisa lembrar de SEO, compliance, capítulos — a IAra cuida do checklist mental
  • Know-how encapsulado: Prompts especializados com experiência real de produção de podcasts
  • Override pontual: Instruções adicionais por vídeo sem alterar o prompt base
  • Compliance proativo: Verificação automática de riscos com argumentos e timestamps
  • Pipeline integrado: Detecção, processamento LLM e publicação via API — zero copiar/colar
  • Parametrização por podcast: Configurações (nome, prompts, channel ID) armazenadas em collection Firestore — PPTNC é o primeiro registro, preparando expansão futura sem refactor

Project Classification

Technical Type: web_app Domain: general (media operations / content publishing) Complexity: medium Project Context: Greenfield - novo app no monorepo existente, artefatos de deploy independentes

Stack: Next.js (compartilha codebase/convenções com portal web), GCP (Cloud Run, Firestore, IAM), Gemini API, YouTube Data API v3 Premissa de stack: Next.js é premissa — compartilhamento de codebase com portal web no monorepo pnpm (apps/iara) Integrações externas: YouTube API (OAuth + CRUD de metadados), Gemini API (geração de conteúdo) Arquitetura: Single-tenant MVP com isolation by design — collection podcasts no Firestore parametriza configurações por podcast para white-label futuro via dados (não código)

Success Criteria

User Success

  • Mecânica eficiente: Cada interação com um vídeo é rápida e objetiva — processar, revisar, finalizar
  • Flexibilidade de uso: Produtor usa na rotina dele — 2 vídeos no intervalo, 10 à noite — sem forçar padrão de sessão
  • Iteração sem fricção: Reprocessar metadados com instruções adicionais até atingir qualidade desejada
  • Autonomia total: Produtor opera sem suporte técnico
  • Continuidade garantida: Rascunhos persistidos por evento (save on blur + save on action) — entra, pega de onde parou, sai

Business Success

  • Adoção total (3 meses): 100% dos vídeos publicados passam pela IAra — nenhum vídeo tratado manualmente fora da plataforma
  • Cadência mantida: Nenhum atraso de publicação causado pelo pipeline de metadados
  • Qualidade SEO consistente: Metadados otimizados para YouTube Search em todos os vídeos, sem variação de qualidade
  • Compliance zero-miss: Nenhum episódio publicado sem verificação de compliance

Technical Success

  • Processamento LLM funcional: Gemini gera metadados completos (título, descrição, capítulos, tags, compliance) a partir da transcrição
  • Persistência confiável: Estado de cada vídeo persistido no Firestore sem perda de dados — save on blur + save on action
  • Integração YouTube bidirecional: Leitura (detecção, transcrição, status) e escrita (metadados, capítulos) via YouTube API funcionando de forma confiável
  • Tratamento de erros: Falhas de API (YouTube, Gemini) comunicadas claramente ao produtor — sem falhas silenciosas

Measurable Outcomes

Product Scope

MVP - Minimum Viable Product

  1. Autenticação: Login via GCP IAM (Google) — mesma credencial para YouTube API
  2. Sincronização: Botão "Verificar novos vídeos" — detecção via YouTube API, classificação por duração
  3. Processamento LLM: Gemini com prompts por tipo (episódio, corte, reel) + instruções adicionais + reprocessar
  4. Compliance: Alerta informativo com argumentos e timestamps
  5. Revisão/Edição: Tela individual de metadados com edição manual e rascunhos persistentes (save on blur/action)
  6. Publicação: Envio em lote para YouTube via API (atualiza metadados)
  7. Portal Web: Criação de registro no Firestore com flag de publicação (data de agendamento)
  8. Gestão de Estado: Status por vídeo (novo → processando → rascunho → finalizado → enviado)
  9. Parametrização: Collection podcasts no Firestore com configurações por podcast

Growth Features (Post-MVP)

  • Integração com Anchor/Spotify (metadados + publicação)
  • Dashboard com métricas de impacto (YouTube Analytics API)
  • Notificações de novos vídeos prontos para processamento
  • Edição de prompts base pela interface (sem dev)

Vision (Future)

  • Processamento automático com aprovação posterior
  • Sugestões de melhoria baseadas em performance histórica
  • Multi-tenant white-label (tenantId, branding, onboarding)
  • Portal web white-label (projeto separado)
