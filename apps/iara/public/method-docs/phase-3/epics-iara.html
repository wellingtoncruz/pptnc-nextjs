IAra - Epic Breakdown

Overview

Este documento fornece o breakdown completo de epics e stories para o IAra, decompondo os requisitos do PRD, UX Design e Architecture em stories implementáveis.

Requirements Inventory

Functional Requirements

Story 1.2: Implementação da State Machine de VideoStatus

Como um sistema, Eu quero uma state machine que gerencie as transições de status dos vídeos, Para que todas as mudanças de estado sejam validadas e previsíveis.

Acceptance Criteria:

Given os estados definidos: new, processing, draft, ready, sending, sent When eu chamo transition(currentStatus, action) Then a função retorna o próximo status válido And lança InvalidTransitionError para transições inválidas

Given um vídeo com status new When eu chamo transition('new', 'process') Then retorna 'processing'

Given um vídeo com status new When eu chamo transition('new', 'send') Then lança InvalidTransitionError

Given um vídeo com status sent When eu chamo qualquer ação de transição Then lança InvalidTransitionError (estado terminal)

And existe um arquivo src/lib/video-state-machine/transitions.ts And existe um arquivo src/lib/video-state-machine/types.ts com:

  • type VideoStatus = 'new' | 'processing' | 'draft' | 'ready' | 'sending' | 'sent'
  • type VideoAction = 'process' | 'complete' | 'error' | 'edit' | 'finalize' | 'send' | 'success'
  • class InvalidTransitionError extends Error And testes table-driven cobrem todas as transições válidas e inválidas And o arquivo de testes está co-localizado: src/lib/video-state-machine/transitions.test.ts

Technical Notes:

  • Pure function sem side effects
  • Usar test.each() para table-driven tests
  • Mapa de transições conforme project-context.md

Story 1.3: Configuração Auth.js com Google Provider

Como um usuário, Eu quero fazer login usando minha conta Google, Para que eu possa acessar o sistema de forma segura.

Acceptance Criteria:
